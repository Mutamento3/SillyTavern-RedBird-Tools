# RedBird 工具箱

一个 SillyTavern 扩展，用来**边玩边学**别人写的预设、大世界卡、MVU 卡和前端卡。

## 安装

1. 打开酒馆 → 顶栏「扩展」→「安装扩展程序」；
2. 粘贴 `https://github.com/RebBirdTD/SillyTavern-RedBird-Tools`，点安装；
3. 装好后刷新页面。从输入框左边的魔法棒菜单 →「RedBird 工具箱」打开，或者发送 `/rbt`。

想用三栏界面（左栏 + 首页角色画廊 + 状态栏）：在「扩展 › RedBird 工具箱」里勾「三栏界面」，或者发送 `/rbt shell`。

**更新**：有新版本时工具箱会弹提示（每天最多查一次，只读 GitHub 上的 manifest.json，不发送任何东西），点提示会打开「管理扩展程序」，在 RedBird 工具箱那一行点更新再刷新页面。也可以在「扩展 › RedBird 工具箱」里点「检查更新」。开了酒馆自己的「在扩展程序更新时通知」的话，酒馆也会提醒。

要求：SillyTavern 1.19 左右，信息流 / 推荐模型只支持 Chat Completion。建议装上酒馆助手（JS-Slash-Runner），MVU 变量卡需要它。


工具箱有 5 个视图，按"用户此刻在做什么"放在不同的地方：

| 视图 | 用来做什么 | 在哪里 |
|---|---|---|
| **角色档案** | 当前这张卡的全部：需要注意的问题、配套环境、来源与说明、换卡时 | 右侧「聊天工具箱」（只在聊天里出现，有问题时按钮上有小圆点） |
| **信息流**、**变量** | 边玩边看：这一轮发给 AI 的内容、变量怎么变 | 右侧「聊天工具箱」，聊天栏自动让位 |
| **全局工具箱** | 按酒馆自己的东西分：预设、世界书、正则、插件、备份 | 左栏「全局工具箱」打开的大 overlay（手机上是聊天工具箱的「全局」标签） |

规则：右边的「聊天工具箱」管"当前这个聊天和这张卡"，首页没有打开聊天时不显示；左栏的「全局工具箱」按预设 / 世界书 / 正则 / 插件 / 备份分标签，「对所有卡生效」是每样东西身上的标记（全局开着 / 正在用），不是单独的标签。工具箱里的交互规则：结尾有 › 的整行在原地打开详情（顶部「‹ 返回」），结尾有 ↗ 的去酒馆面板或网页，其余文字不可点。打开方式：魔法棒菜单 →「RedBird 工具箱」，或输入 `/rbt`（`/rbt card / flow / vars / presets / worlds / regex / plugins / backup` 直接打开对应视图）。所有开关都在 扩展 → RedBird 工具箱 里。

## 三栏界面

- **状态栏**：聊天时导航条右边像 Mac 菜单栏一样显示现在用的预设和「API · 模型」（所有 API 类型都显示），「世界书（N）」写着这个聊天加载了几本世界书（悬停看是哪几本）。「编辑卡片」在左边角色名旁边。和这张卡推荐的不一样、API 没连上、或者全局开着别的卡的世界书时，前面亮一个琥珀色小点；点一下打开酒馆对应的面板。

在「扩展 › RedBird 工具箱」里打开（新装默认关着），用 ChatGPT 式的布局代替酒馆原来的顶栏图标：

- **左栏**：首页按钮；最上面并排两个按钮：「导入文件」（实心主题色，整个界面唯一的主按钮）和「全局工具箱」（工具箱自己的：全局 / 维护）；下面是酒馆自带的入口（预设、扩展·正则、API、人设 / 设置、背景、格式化，API 没连上时有小圆点）；然后是「最近聊过 / 最近导入」切换和搜索（刚导入、还没聊过的卡在「最近导入」里找）；最下面是临时聊天、文档 / GitHub / Discord、原版界面和版本号。« 可以收起。
- **首页**：中间是角色画廊（竖版大卡片，立绘铺满，底部用图片自己的颜色托住名字），上面有搜索、筛选（收藏 / 待处理 / 群组 / 标签）、排序、管理和「＋ 新建」（新建角色 / 新建群组）。电脑上导入走左栏的「导入文件」；手机上左栏收在 ☰ 里，所以「新建」旁边也放了一个「导入文件」。
  - **聊天**：按「置顶 / 今天 / 昨天 / 7 天内 / 30 天内 / 更早」分组的最近聊天。
  - **角色**：角色库。可以按收藏、标签、群组、有问题的、没填来源链接的筛选，按最近聊过 / 名称 / 最近添加排序；新建、导入（文件 / 链接）、建群组、维护；有问题的卡在行里直接标出来（世界书没导入、脚本没启用…）；鼠标移到一行上可以收藏或编辑。收藏和标签就是酒馆原来的数据。
- **导航条**：显示「角色名 · 存档」，点存档名可以切换或管理存档；旁边是「＋ 新聊天」（只在聊天里出现）；右边是「编辑卡片」（酒馆原来的角色编辑页）、世界书、聊天工具箱。打开世界书面板时，标题栏列出这次实际加载的书（可以点），换卡后第一次打开会自动显示这张卡的书。
- **面板**：所有面板都是居中的大 overlay（API 是单栏表单，窄一些），背后压暗，不和聊天挤在一起。每个都有标题栏和 ×，按 Esc 或点压暗处都能关。原则是每个时刻只专注一件事：浏览、切换放在左栏，编辑、设置用 overlay。
- **随时切回原版**：左栏底部「原版界面」、扩展设置里的「三栏界面」开关，或输入 `/rbt shell`。
- **手机上**（窗口窄于 1000px）：同一套界面换个排法——左上角 ☰ 打开左栏（当前角色的编辑卡片 / 世界书 / 存档、全局工具箱、酒馆的各个面板、最近的聊天）；顶栏中间是角色名，点它切换存档；右上角是新聊天和聊天工具箱。面板、工具箱、导入窗口都全屏，两栏的页面变成一栏，状态栏不显示。

外壳不重做酒馆的面板，只改它们出现的位置；开关面板都是点酒馆自己的按钮，所以钉住、互斥这些原有行为都保留。

## 美化

工具箱自带三套美化（深色、浅色、护眼），只改「长什么样」：颜色、字体、字号、间距和圆角，不改布局（布局是三栏界面的事）。三栏界面、原版界面、工具箱自己的窗口都用同一套颜色，所以看起来是一个软件。消息里卡片自己画的界面（状态栏、面板这些）不会被改。

- 开关在「扩展 › RedBird 工具箱 › 美化」。在「全局工具箱 › 美化」里选深色（苹果风，晚上玩）/ 浅色（米白书页，白天读长文）/ 护眼（暖黄纸色），以及强调色（蓝、珊瑚、粉、紫、绿、石墨）。
- 聊天正文排成一栏居中，一行 44 个字左右（再宽眼睛换行容易找错行），输入栏和这一栏对齐、四周留白；消息不加圆角。圆角只用一套尺寸（4 / 8 / 12 / 16 / 20），嵌套时内外同心。
- 聊天内容区全是中性色（你的消息底色、对白、旁白都不带颜色），强调色只用在按钮、当前项这些可以点的地方。
- 自带的三套是按三栏界面做的，推荐用这些。换成别人做的美化（带自定义样式的）之前会提醒一次：那是按酒馆原版界面做的，在三栏界面里个别地方可能不协调；可以勾「以后不再提醒」。
- **全局工具箱 › 美化**：左边是正在用的（工具箱自带的，或者某个酒馆主题），一键切换；右边是装着的所有美化，标出「带自定义样式」还是「只换颜色」，带几个关键颜色的小色块，可以按系列分组。点进去能看配色、记作者和链接、版本和更新说明，「换成这个」或删除（删之前自动备份到 user/files）。
- 想用别人做的美化：把主题文件（.json）拖进导入窗口，会认成「美化」。勾上「导入后换成这个美化」会顺便关掉工具箱自带的，免得两套打架。
- 已经在用别人的美化（酒馆主题里带自定义 CSS）的，第一次装工具箱时美化默认关着。
- 关掉自带美化、用别人的美化时，三栏界面和工具箱的颜色从那套主题算出来：浅色主题就是浅底深字。
- 别人的美化可以改颜色、字体、消息排版和输入框的形状；但三栏界面的骨架（左栏、导航条、聊天区和输入区的位置、面板和工具箱）以工具箱为准。
- 在酒馆自己的「用户设置 › 界面主题」里换主题，也会自动关掉工具箱自带的美化（会弹提示）。

## 现在有的工具

### 信息流
每次真正发送请求时，捕获**这一轮实际发给 AI 的全部消息**，并标出每一段来自哪里：

- 预设里的哪个条目（用的是提示词管理器里的真实名字）
- 角色卡字段（描述、性格、场景、示例对话、卡内系统提示词覆盖）
- 世界书：哪本书的哪一条，这本书属于角色 / 聊天 / 用户设定 / **全局**
- 聊天记录的第几楼，以及插在聊天记录中间的深度注入（显示深度）
- 扩展注入（作者注释、总结、向量等）

顶部的色条显示各来源占了多少 token（估算）。

最上面的「额度」：上下文上限和回复上限（就是预设里的「上下文长度」和「最大回复长度」），这一轮发出去多少、留给回复多少、还空着多少。上一条回复写到了回复上限的 90% 以上，会提醒「很可能被截断了」；上下文放不下、最早的聊天记录被挤掉，也会提醒。「去改 ↗」直接打开预设面板。「触发的世界书」页列出这一轮触发的条目，以及在最近消息里匹配到的关键词。

「预览下一轮（不发送）」走的是酒馆自己算 token 时的路径：不会发送请求、不花钱，也不会改动聊天。预览时酒馆不报告逐条触发的世界书，所以世界书只按"@深度"整块显示。

> 目前只支持 Chat Completion 模式。

### 变量
列出这张卡在**跟踪的所有变量和现在的值**（读每一楼的 MVU `stat_data`，兼容旧版 `[值, "说明"]` 格式），按第一层分组。这一轮变了的前面有个小点，下面灰字写原来的值；可以「只看变了的」，也可以切到某一楼看当时的值。点一个变量展开：变量说明，以及当前生效的世界书和预设里哪些条目用到它。会把整个 `stat_data` 发给 AI 的条目在顶部单独说明。

### 角色档案
- **需要注意**：页面最上面列出没到位的东西，每条带修复按钮（导入世界书、切到推荐预设、允许卡内正则、启用插件并刷新…）。
- **配套环境**：世界书（绑在卡上的显示"已加载"，和卡里内嵌版本对比，可以用卡里的版本覆盖并先备份）、推荐预设、卡内正则和酒馆助手角色脚本、需要的插件。
- **来源与说明**：卡里写的联系方式和作者备注，加上自己记的链接（DC 发布帖等）和作者说明。
- **换卡时**：换到这张卡时自动把预设、全局世界书、全局正则切成它的配套环境——有「记住的配置」就照着来；没有时只做确定该做的事（关掉别的卡的世界书、关掉标了属于别的卡 / 预设的全局正则、切到推荐预设）。卡里带的世界书没导入会先导入。切换排在所有扩展之前完成，MVU 初始化变量时看到的就是对的世界书。每次自动切换都能撤销。插件没法在运行中开关，只提示「启用并刷新」。

### 全局工具箱
- **导入**：点左栏「导入文件」，先打开导入窗口：中间是虚线拖放区（把文件拖进来，或点「选择文件」，可以多选），下面列出支持的类型，底部是「从链接导入角色卡」。三栏界面里把文件拖到窗口任何地方也行（聊天输入框除外，那里还是酒馆的附件）。会自动认出是预设、世界书、正则、角色卡还是美化（可以一次拖好几个、混着拖），然后在同一个窗口里列出每个文件：每个文件可以勾「导入后换成这个预设 / 作为全局世界书打开 / 打开这张卡」，也可以顺手填作者、链接和备注（存进对应的档案）。都不勾不填就是普通导入。作者同时发了 PNG 和 JSON 的：会读出文件里的卡名，同一张卡只导入 PNG（带头像）；和卡一起发的世界书，如果就是卡里自带的那本会提示不用导入，否则可以直接绑到这张卡上；一起发的预设可以直接设成这张卡的推荐预设。用的是酒馆自己的导入功能，酒馆原来的提示照常出现（导入正则时酒馆会问放到全局 / 这张卡 / 预设）。
- **换预设时模型被换掉**：酒馆的「将预设与 API 配置绑定」开着时，换预设会把预设里存的 API 和模型也换上。工具箱会提示「模型从 A 换成了 B」，点一下换回；预设里没存模型、模型被清空时，自动换回原来的。
- **编辑正则和脚本**：列出正则和酒馆助手脚本的地方，旁边都有 ✎：单条正则直接打开酒馆的正则编辑窗口，一组正则打开正则面板的那一组，脚本打开酒馆助手面板。
- **推荐模型**：角色卡（角色档案 › 推荐预设和模型）和预设（预设详情）都可以记一个「API + 模型」，「用现在的模型」一键填上。换卡时先换预设、再换模型：这张卡的推荐模型优先，没有就用它推荐的预设的推荐模型；能撤销。预设详情里也会写出预设文件自己带的连接——酒馆开着「预设绑定连接」时，换预设会顺带换 API 和模型，这里提前告诉你。
- **预设**：最上面是正在用的预设（切换、编辑、自带正则逐条开关）；下面是你保存的所有预设，按系列分组、版本从新到旧。名字里的版本号（v1.1.7、8.0…）会自动读出来；名字开头相同的会提示「可能是同一系列」，一键归组。点一个预设打开详情：作者和链接（发布帖、教程…）、系列 / 版本 / 更新说明、推荐它的卡、同系列的其他版本，可以直接「换成这个」。
- **世界书**：全局开着的（开关、再打开一本）、没绑在任何卡上的、绑在卡上的（写着是哪些卡）。卡里自带但还没导入的世界书在最上面一键全部导入。点一本打开详情：作者和链接、系列 / 版本 / 更新说明、用到它的卡、作为全局世界书开关、「在世界书里打开 ↗」。
- **正则**：全局正则逐条开关、标「属于谁」（换卡时自动开关）；酒馆助手全局脚本；带正则的卡和带正则的预设（点进去看详情）。
- **插件**：最上面粘贴 Git 链接就能安装（走酒馆自己的安装流程和第三方提醒）；下面每个插件一个开关，改完点「保存并刷新」。点插件名展开作者和链接：插件自己 manifest 里写的作者和主页会自动带出来，也可以自己加教程等链接。
- **美化**：见上面「美化」一节。
- **备份**：把工具箱里填的所有东西导出成一个文件 / 导入（合并或覆盖）；覆盖世界书前自动做的备份；找不到卡的档案（转给新卡或删除）。

## 数据存在哪

工具箱里填的东西（卡的来源和说明、推荐预设、记住的配置、正则归属，预设 / 世界书 / 插件的作者、链接、系列和版本）存两份：

- 酒馆的 `data/<用户>/settings.json` 里的 `extension_settings.redbird_tools`（跟着酒馆设置走）；
- 工具箱自己的 `data/<用户>/user/files/redbird-tools.json`。

酒馆保存设置是整份覆盖，开着的另一个旧页面一保存就可能盖掉新填的内容。第二份文件每次写之前都会先读回来，按每条记录的修改时间合并（删除也会记下时间），打开酒馆时也会用它把 settings.json 里旧了的部分补回来，所以不会因为多开页面丢东西。「全局工具箱 › 备份」可以再导出一份单独的文件。

## 开发

```bash
npm install
npm run watch     # 改代码后自动构建到 dist/
npm test          # 单元测试（来源归因、变量对比）
npm run typecheck
```

本地调试：在 `SillyTavern/data/default-user/extensions/` 下建一个指向本仓库的目录链接（Windows 用 `mklink /J`），然后刷新酒馆页面。

结构：

```
manifest.json        酒馆扩展清单（加载 dist/index.js、dist/style.css）
src/index.tsx        入口：注册事件、菜单、/rbt 命令、侧边栏
src/st/st.ts         和酒馆打交道的唯一地方（getContext、动态 import 酒馆模块、斜杠命令）
src/core/            纯逻辑，可单测：来源归因、消息对齐、变量对比
src/tools/flow/      信息流：捕获提示词
src/tools/vars/      变量：楼层变量和引用搜索
src/tools/env/       环境报告、每卡记住的配置、换卡自动套用（autoapply.ts）
src/tools/cards/     卡的信息：来源、推荐预设、需要的插件、世界书导入与对比、正则归属
src/shell/           三栏外壳：左栏、导航条、酒馆面板的位置（drawers.ts）、最近聊天（recent.ts）、角色库（characters.ts）、大 overlay（Sheet.tsx）
src/ui/views.ts      所有视图和"在哪里打开"的规则
src/ui/pages/        这张卡 / 全局 / 维护 三个页面
src/ui/              信息流、变量和侧边栏
```

`dist/` 需要提交：从 GitHub 安装扩展时，酒馆直接加载里面的文件。
