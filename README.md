# RedBird 工具箱

RedBird 工具箱是一个 SillyTavern（酒馆）扩展，方便你边玩边看懂角色卡、预设、世界书和变量，也能管理换卡时要用的配套。

你可以用它：

- 玩卡前检查世界书、预设、正则和脚本有没有准备好。
- 查看这一轮实际发给 AI 的内容，找出提示词来自哪里、上下文花在哪里。
- 查看 MVU 变量现在的值、哪一楼发生了变化、哪些提示词用到了它。
- 给角色卡、预设、世界书和美化记下作者、来源、版本和使用说明。
- 换卡时自动切换配套，发现不对时撤销；也可以给角色卡配一套美化，和它聊天时整个界面换过去。
- 按需要开启「三栏界面」和「红鸟适配美化」，整理日常玩卡的入口。

本文件是功能说明的统一来源。版本变化见 [CHANGELOG.md](CHANGELOG.md)；Discord 等渠道的介绍从这里取材，宣传帖子和图片另行存放。

## 安装与更新

### 安装

1. 打开酒馆顶栏的「扩展」，选择「安装扩展程序」。
2. 粘贴仓库地址：`https://github.com/RebBirdTD/SillyTavern-RedBird-Tools`。
3. 安装完成后刷新页面。
4. 从输入框左边的魔法棒菜单打开「RedBird 工具箱」，或输入 `/rbt`。

新安装时，「三栏界面」默认关闭。想使用左栏、首页角色画廊和聊天状态栏，可以在「扩展 › RedBird 工具箱」里打开「三栏界面」，或输入 `/rbt shell`。

### 使用要求

- 在 SillyTavern 1.19 上开发和测试，更早的版本没有测过。
- 「信息流」和推荐模型功能只支持 Chat Completion。
- 建议安装酒馆助手（JS-Slash-Runner）；MVU 变量卡需要它。

### 更新

工具箱每天最多检查一次新版本，只读取 GitHub 上的 `manifest.json`，不发送你的聊天或设置。

有新版本时，「扩展 › RedBird 工具箱」顶部会显示「有新版本 x.y.z」和「更新」按钮。点「更新」即可更新工具箱。每天的新版本提示通知也可以直接点来更新。

也可以在扩展设置底部点「检查更新」。发现新版本后，会询问「现在更新吗？」。

这里的更新和在酒馆「管理扩展程序」里点更新一样。更新完成后，会询问「刷新页面后新版本才会生效。现在刷新吗？」。

为所有用户安装的工具箱只有管理员能更新，无法更新时会提示原因。更新失败时，可以点通知里的入口打开「管理扩展程序」手动更新。

如果开启了酒馆自己的「在扩展程序更新时通知」，酒馆也会提醒。

## 先找到要用的工具

「聊天工具箱」管当前聊天和角色卡；「全局工具箱」管你安装、保存的各类资源。

| 入口 | 适合什么时候用 | 在哪里 |
|---|---|---|
| 「角色档案」 | 玩卡前检查配套，记录来源，设置换卡时的行为 | 「聊天工具箱」 |
| 「信息流」 | 看这一轮发给 AI 的内容，排查提示词和上下文 | 「聊天工具箱」 |
| 「变量」 | 看 MVU 变量的当前值和逐楼变化 | 「聊天工具箱」 |
| 「全局工具箱」 | 查看和解绑角色配套，管理预设、世界书、正则、脚本、插件、美化和备份 | 三栏界面的左栏；原版界面里在工具箱的「全局」标签 |

「聊天工具箱」只在打开聊天后出现。角色档案里有「需要注意」的问题时，入口上会显示琥珀色的数字，写出有几项。宽屏打开后，聊天栏会给它让出位置；工具箱左边缘可以拖动调宽，宽度会在当前浏览器里记住。窄屏时，工具箱覆盖顶栏下方的区域。

「聊天工具箱」标题栏右边是导出诊断文件的「⤓」和关闭按钮「✕」，下面用分段式标签切换「角色档案」「信息流」「变量」。

使用原版界面时，可以从魔法棒菜单或扩展设置打开工具箱。在「扩展 › RedBird 工具箱」的「工具箱」分组里，点「聊天工具箱」查看当前聊天和角色卡，点「全局工具箱」管理已安装、保存的资源。这两项整行都可以点，右侧有「›」。每项下方都有一句用途说明。「界面」分组里依次是「三栏界面」「红鸟适配美化」「手机沉浸阅读」；「手机沉浸阅读」默认打开，只在开着「三栏界面」时显示。「换卡时」分组里可以设置自动换成这张卡的预设、世界书和正则、换成这张卡的美化，以及自动导入卡里自带的世界书。版本号、「检查更新」和「使用说明 ↗」放在最下面一行。「使用说明 ↗」链接到本文件。

工具箱里的列表有统一的打开方式：

- 行尾是 `›`：在当前窗口打开详情，顶部的「‹ 返回」回到上一页。
- 行尾是 `↗`：打开酒馆面板或网页。
- 其余说明文字不可点击。

### `/rbt` 命令

| 命令 | 用途 |
|---|---|
| `/rbt` | 打开工具箱 |
| `/rbt card` | 打开「角色档案」 |
| `/rbt flow` | 打开「信息流」 |
| `/rbt vars` | 打开「变量」 |
| `/rbt table` | 打开「全局工具箱 › 角色」，查看和解绑角色配套 |
| `/rbt presets` | 打开预设管理 |
| `/rbt worlds` | 打开世界书管理 |
| `/rbt regex` | 打开正则管理 |
| `/rbt scripts` | 打开脚本管理 |
| `/rbt plugins` | 打开插件管理 |
| `/rbt backup` | 打开备份 |
| `/rbt shell` | 开启或关闭「三栏界面」 |

## 导入角色卡和配套文件

作者把角色卡、世界书、预设放在一起发布时，可以一起导入，不必先逐个判断文件类型。

在三栏界面左栏点「导入文件」。手机上也可以点首页「＋ 新建」旁边的「导入文件」。

1. 把文件拖进虚线区域，或点「选择文件」，支持多选。
2. 工具箱会识别角色卡、预设、世界书、正则、美化和酒馆助手脚本，在同一个窗口列出待导入的文件。
3. 核对文件和配套关系，按需要勾选导入后的操作。
4. 填写作者、链接和备注后导入；这些信息会存入对应档案。不填也可以正常导入。

窗口底部的「从链接导入角色卡」可以从链接导入角色卡。

三栏界面还支持把文件拖到窗口其他位置，放下前会显示导入提示。聊天输入框仍按酒馆原来的方式处理附件；酒馆弹窗和导入窗口也保留各自的拖放行为。

### 导入前可以顺手设置什么

每个文件都有对应选项，例如：

- 预设：「导入后换成这个预设」。
- 世界书：「导入后作为全局世界书打开」。
- 角色卡：「导入后打开这张卡」。
- 美化：「设为全局美化」。
- 酒馆助手脚本：「导入后马上运行」。脚本会放进全局脚本；不勾就先关着，以后在「全局工具箱 › 脚本」里打开。和美化一起导入、只在那套美化下起作用的脚本，默认勾上，说明里写「「美化名」要靠它才完整。用别的美化时它不起作用」。

同一批文件的来源可以统一填写。导入后的操作都不勾选，就是普通导入。

### 和角色卡一起发布的文件

工具箱会读出 PNG、JSON 里的角色卡名称，帮助你处理配套文件：

- 同一张卡同时提供 PNG 和 JSON 时，默认只导入带头像的 PNG。
- 世界书与卡里自带的那本相同时，会标为「不导入」，避免重复导入。名字不同时，还会核对条目，不会只因条数接近就跳过；其他配套世界书仍可正常导入并绑定到卡上。
- 其他配套世界书可以直接绑定到这张卡；卡已有世界书时，可以作为额外世界书。
- 一起导入的预设可以设为这张卡的推荐预设。
- 一起导入的美化可以「设为「卡名」的美化」，和这张卡聊天时整个界面换成它。

被跳过的文件会集中提示，需要时可以选择「仍然导入」。

开启扩展设置里的「自动导入卡里自带的世界书」后，用「导入文件」导入自带世界书的角色卡时，世界书会当场导入并绑定到卡上，不再弹出酒馆的英文导入确认，也不会自动打开世界书面板。

其他导入确认仍使用酒馆自己的流程。例如导入正则时，酒馆会询问放到全局、当前角色卡还是预设。

## 角色档案：先把这张卡准备好

在「聊天工具箱」打开「角色档案」，可以检查当前卡缺什么、记下来源，并设置换卡时要用的环境。

第一块显示头像、名字、作者、版本和标签，右上角的「编辑角色 ↗」打开酒馆的角色编辑页；如果看的不是当前聊天中的角色，会先打开这张卡再进入编辑页。同一块里接着显示来源和作者说明。

### 「需要注意」：检查没准备好的地方

有问题时才显示「需要注意」，每条都有对应操作，例如：

- 导入缺少的世界书。
- 换到推荐预设。
- 允许卡内正则运行。
- 启用需要的插件并刷新。
- 检查当前模型是否符合推荐。

可以先从这里处理问题，再开始聊天；没有问题时，这一块不显示。

### 「配套」：查看这张卡依赖什么

这里列出：

- 世界书及加载状态。
- 推荐预设和模型。
- 绑定到这张卡的 user 人设及使用状态。
- 卡内正则。
- 酒馆助手角色脚本。
- 需要的插件及安装、启用状态。
- 这张卡的美化。

这里的东西都跟着角色卡走，对这张卡的所有存档都生效。

正在聊的卡有问题时，修复按钮只放在上面的「需要注意」里，例如「刷新页面」「导入并绑定」；下面的分区只显示状态。

绑定到卡上的世界书会显示「已加载」。工具箱还会比较已导入的世界书与卡内嵌版本；需要使用卡里的版本时，可以覆盖，覆盖前会自动备份。

各块右上角的按钮可以打开酒馆对应面板：世界书是「编辑 ↗」，推荐预设和模型是「预设设置 ↗」「API 设置 ↗」，user 人设是「人设设置 ↗」，正则是「编辑 ↗」，需要的插件是「插件设置 ↗」。「美化」右上角的「查看全部美化」打开「全局工具箱 › 美化」。单条正则的编辑按钮打开正则编辑窗口，一组正则的编辑按钮打开那一组。

装了酒馆助手（JS-Slash-Runner）时，正则和脚本分开显示，原来的「正则与脚本」改叫「正则」，后面是「角色脚本」，卡没有脚本时不显示这一块。「允许运行」控制整组脚本，下面的勾选框分别控制文件夹和脚本，开关方式与「全局工具箱 › 脚本」相同。

正在聊的卡可以开关单个脚本，右上角的「编辑 ↗」打开酒馆助手，可以编辑、新建或导入脚本。其他卡只能开关整组「允许运行」，单个脚本的勾选框是灰的，并提示「要开关单个脚本，先打开这张卡。」，也不显示「编辑 ↗」。

### 「来源与说明」：把发布帖和食用说明留在卡旁边

来源和作者说明放在卡面信息的同一块里，显示卡里写的联系方式和作者备注。你也可以补充来源链接、Discord 发布帖、教程和自己的作者说明，之后不用再翻聊天记录找。

「来源和作者说明」里的链接整行可点，点击后在新标签页打开；每行左边是图标（Discord 链接显示 Discord 图标），中间是名字和网址，右边是打开标记。每行右侧的「⋯」菜单依次提供「编辑」「复制链接」和「删除」。选择「编辑」后，这一行会变成名称和网址两个输入框，后面显示「保存」「取消」；点击「保存」或按回车保存，点击「取消」或按 Esc 取消。网址可以不写 https://，工具箱会自动补上。删除后会提示「已删除链接「名字」。点这里撤销。」，8 秒内点击提示即可恢复。添加链接时，点击「＋ 添加链接」展开名称和网址输入框，再选择「添加」或「取消」；平时只显示「＋ 添加链接」。

### 推荐预设和模型

在「角色档案 › 推荐预设和模型」里，可以给这张卡记下推荐预设，以及推荐的「API + 模型」。「用现在的模型」可以直接填入当前连接。

在「推荐预设」下拉里选好预设后，如果是正在聊的卡，会马上切到这个预设，再切到这张卡的推荐模型；卡没写推荐模型时，使用这个预设记下的推荐模型。切换过程中不会再弹模型被预设换掉的提醒。其他卡只记下选择，不切换当前预设和模型。

正在用的就是推荐的时，旁边显示绿色勾；不一样时，下面用琥珀色写出正在用的预设或模型，切换按钮放在顶部的「需要注意」里。

换预设前后，只要其中一个预设带着正在运行的酒馆助手脚本，就会提醒「刷新页面后再发消息」，并说明「换了带脚本的预设，不刷新的话，发消息可能会卡住。」。从工具箱、酒馆预设面板或换卡时自动切换都会提醒，没有脚本的预设之间切换不提醒。

提醒会出现在「需要注意」和这里，也会显示在「全局工具箱 › 预设」的「正在用」下面及正在用的预设详情里。「需要注意」里的预设一项不再显示原来的绿色勾；这里正在用的推荐预设旁边会改为琥珀色感叹号。点「刷新页面」会先保存酒馆设置，换好的预设不会丢。刷新后提醒消失。

预设详情也可以记录推荐模型。换卡时先切预设，再切模型：

1. 优先使用角色卡的推荐模型。
2. 角色卡没写时，使用它推荐的预设所记录的推荐模型。

推荐模型只支持 Chat Completion。自动切换后可以撤销。

### user 人设

「配套」里的「user 人设」位于「推荐预设和模型」下面。换到这张卡时，酒馆会自动换成绑定的人设；右上角的「人设设置 ↗」可以打开酒馆人设面板。

这里列出绑定到这张卡的人设头像和名字，正在用的有绿色勾，每行可以「解绑」。正在聊的卡如果绑了别的人设，对应行会显示「换上」，并用琥珀色写出现在用的人设。没有绑定时显示「没有绑定人设。」

下面的「绑定」下拉框可以直接选一个人设绑到这张卡，不用先去人设面板换过去；现在用的人设排第一，标「（现在用的）」。正在聊的卡选了会马上换上。酒馆没开「允许一个角色连多个人设」时，选一个就是换掉原来绑的，8 秒内可以点提示撤销。

这个存档在酒馆里锁定了别的人设时，会写「这个存档锁定了人设「X」，会盖过卡上绑的。只对这个存档。」。存档锁定的人设优先于卡上绑的，所以这时候用的是锁定的那个。

这里使用酒馆自己的「连接到角色」，与酒馆人设面板共用同一份数据。换卡时由酒馆自动换人设，工具箱不另外切换。

在三栏界面的聊天里，点自己消息的头像，也会打开酒馆的人设面板。

在角色档案里解绑推荐预设、推荐模型、user 人设或美化后，右上角会提示「已解绑「名字」。点这里撤销。」，8 秒内点提示可以恢复，和「全局工具箱 › 角色」一样。

### 美化（跟着角色卡）

「配套」最后的「美化」可以给这张卡选一套美化。和这张卡聊天时，整个界面换成这套美化；回首页或换到没设美化的卡，换回全局美化。默认的「用全局美化」表示不换。正在用这张卡的美化时，旁边有绿色勾；选的美化被删掉时，写「（已经删掉了）」。

换卡时先显示聊天，下一帧再换上卡的美化；美化比较大、要零点几秒才换好时，顶栏下沿会出现进度条。换上卡的美化时，不改酒馆自己的主题设置：你调过、没存进主题的颜色和选项不会丢。字号、聊天宽度、头像形状、计时这些阅读习惯也不跟着换。卡的美化盖着时，在酒馆「用户设置」里换主题、改自定义 CSS，看到的仍是卡的美化；打开那里时会提醒一次，回首页就能看到改动。在酒馆里保存美化后，卡的美化也会用上新版本。

正在聊的卡，「美化」下面还有一行「背景」：下拉框里选一张，就只给这个存档用，不改全局背景；换到别的存档或别的卡用全局背景，回来还是选的那张。选「跟着全局背景」恢复成和别的存档一样。这就是酒馆背景面板上「锁定到这个聊天」的那个设置，两边同步；新开的聊天需要再选一次。

「换到这张卡时」里的「换成这张卡的美化」关掉后，所有卡都用全局美化，已经选好的不会丢；扩展设置的「换卡时」里也有同一个开关。

很多美化会带一个酒馆助手脚本，比如「仿 Claude UI」。这类脚本通常自己判断现在是不是这套美化，不是就不起作用，所以放在全局脚本里一直开着就行，美化绑到卡上时也会跟着进出。

### 「换到这张卡时」：自动切换配套

打开「自动换成这张卡的预设、世界书和正则」，换到这张卡时会自动调整配套。

还没记住时，「记住现在的配套」按钮上面会先显示「记住后，每次换到这张卡都恢复成这一套：」，按六行列出换到这张卡时会换成的预设、模型、user 人设、美化、全局世界书和全局正则，和「全局工具箱 › 角色」里的六项一样。模型没指定时写「没指定，用预设推荐的」，没绑人设时写「没绑定」，没设美化时写「用全局美化」，没有全局世界书或全局正则时写「全部关掉」，有全局正则时写「打开 N 条」。

点「记住现在的配套」，可以为这张卡记住当前的预设、全局世界书和全局正则；之后每次换到这张卡都会恢复这一套，模型按推荐模型规则切换。记住后也按同样六行显示；记住的世界书后来被删掉或改名时，写「（已经删掉了）」，不再算作改动。

正在聊这张卡时，如果全局世界书或全局正则和记住的不一样，角色档案底部会浮出一条提示，例如「世界书 1 处和记住的不一样」，可以点「恢复」换回记住的，或点「记住改动」更新记住的内容。「记住改动」只更新世界书和正则，不会把临时换的预设变成推荐预设。「恢复」没能完成时，提示会写出是哪几项。

「不再记住」只忘掉记住的全局世界书和全局正则，推荐预设、推荐模型和美化都保留；点完 8 秒内可以点提示撤销。

没有记住的配置时，只做资料能确定的调整：

- 卡内嵌的世界书尚未导入时，先导入，不覆盖已有版本。
- 关闭别的卡的世界书。
- 关闭标记为属于别的卡或预设的全局正则。
- 切到这张卡的推荐预设。
- 按推荐模型规则切换模型。

换卡时，酒馆会先等工具箱自动切换配套、导入卡内世界书，最多等 4 秒；超过就先显示聊天，剩下的在后台做完。通常 MVU 会使用切换后的世界书初始化变量；网很慢时，MVU 或酒馆助手可能先按旧世界书初始化，等切换完成后重新开一次聊天即可。每次自动切换都可以撤销。

换卡过程中，顶栏下沿会显示一条细进度条，0.5 秒内换完不显示；超过 4 秒先显示聊天时，进度条会留到后台切换完成。

插件不能在运行中直接开关。需要调整时，工具箱会提示「启用并刷新」。

## 信息流：看这一轮到底发给了 AI 什么

在「聊天工具箱」打开「信息流」。每次真正发送 Chat Completion 请求时，它会记录这一轮实际发出的全部消息，并标出来源。

分析会等页面空闲时进行，最多晚 1.5 秒出结果，减少世界书条目多、聊天长时的卡顿。手机保留最近 10 轮，电脑保留最近 20 轮；每轮都存着整份提示词，限制轮数可以减少长上下文占用的内存，降低手机页面被系统重新加载的可能。

| 来源 | 能看到什么 |
|---|---|
| 预设 | 提示词管理器里的真实条目名 |
| 角色卡 | 描述、性格、场景、示例对话、卡内系统提示词覆盖 |
| 世界书 | 哪本书、哪一条，以及属于角色、聊天、用户设定还是全局 |
| 聊天记录 | 第几楼，以及插在聊天记录中的深度注入和深度 |
| 扩展 | 作者注释、总结、向量等扩展注入 |

顶部色条显示各来源的 token 占比，总数用酒馆这一轮自己算的数，各来源仍按估算的占比分配总数；拿不到酒馆的数时，总数仍用原来的估算。消息列表会显示 token 数、角色、深度、来源等信息，并提供内容预览。

### 「额度」：检查上下文和回复空间

「额度」显示预设里的「上下文长度」和「最大回复长度」，以及这一轮：

- 发出了多少内容。
- 留给回复多少空间。
- 还剩多少空间。

这一轮发出去的 token 总数用的是酒馆自己算的数，拿不到时仍用原来的估算。

上一条回复达到回复上限的约 90% 时，会提醒可能被截断。上下文放不下、较早聊天记录被挤掉时，也会提醒。

点「去改 ↗」可以打开预设面板调整。每轮记录保留当时的额度，之后改预设不会改变旧记录里的上限。

### 「触发的世界书」

这一页列出本轮触发的世界书条目，以及在最近消息里匹配到的关键词，方便检查某条为什么进了提示词。

### 「预览下一轮（不发送）」

想在发送前检查提示词，可以点「预览下一轮（不发送）」。

预览使用酒馆计算 token 的流程，不发送 AI 请求、不花费模型额度，也不改动聊天。预览时酒馆不报告逐条触发的世界书，因此世界书会按 `@深度` 整块显示。

## 变量：查看当前值和逐楼变化

在「聊天工具箱」打开「变量」，可以查看 MVU 卡跟踪的所有变量。

工具箱读取各楼的 MVU `stat_data`，兼容旧版 `[值, "说明"]` 格式，按第一层分组显示。

- 默认看变量的当前值。
- 本轮变化的变量前有小点，下方灰字显示原来的值。
- 开启「只看变了的」，可以集中检查这一轮的变化。
- 切到某一楼，可以查看当时的变量值。

点开变量，可以查看说明、变量路径，以及当前生效的世界书和预设中哪些条目用到了它。会把整个 `stat_data` 发给 AI 的条目，会在顶部单独说明。

## 全局工具箱：管理已经装进酒馆的资源

在三栏界面左栏点「全局工具箱」（手机上在 `☰` 里）。原版界面里在工具箱的「全局」标签。

这里依次是「角色」「预设」「世界书」「正则」「脚本」「插件」「美化」「备份」。打开时默认显示「角色」，一张表查看和解绑每张卡的配套。其他资源在宽屏上通常左边显示正在生效的内容，右边显示已有资源；手机改为一栏。

“全局”表示某个资源对所有卡生效，是资源上的状态，不是单独的分类。

预设、世界书和美化列表右上角的「选择」（原「整理」）可以批量归组或删除。点开后，每行出现勾选框，顶部显示「已选 N 个」「全选」「完成」；底部可点「归入系列」「移出系列」或红色的「删除 N 个」，点「归入系列」后才出现系列名输入框。正在用的预设和酒馆主题不能选，也不能删。

删除前会列出资源名称；预设被角色卡推荐时会提醒推荐会失效，世界书绑在卡上时会列出是哪些卡。确认后先备份到 `data/<用户名>/user/files`，备份失败就不删。删完后，15 秒内点「已删除…，点这里撤销」通知即可恢复；世界书原来全局开着的会重新打开，正则会放回原来的位置。

### 角色

在这里一张表看完每张卡换卡时要用的配套，也可以直接解绑。输入 `/rbt table` 同样可以打开。

顶部可以「搜索角色」，切换「有配套的」「全部角色」，右边显示「N 张卡」。默认显示「有配套的」：设了推荐预设或模型、记住了换卡设置、或绑了人设的卡。正在聊的卡排第一，并标出「正在聊」。

电脑上按表格显示，列出角色、预设、模型、user 人设、美化、全局世界书和全局正则。后六列上方是「换到这张卡时换成」，旁边写着「「—」表示不换」。

- 模型只显示名字，鼠标移上去可以看 API 和模型全称。卡没单独设模型、使用推荐预设记下的模型时，下面写「用预设推荐的」。
- 卡没绑人设、酒馆设了默认人设时，会显示默认人设的名字，下面写「酒馆的默认人设」。
- 卡没设美化时写「全局美化」。选的美化被删掉时，下面写「找不到这个美化，不会换」；「换成这张卡的美化」关着时，写「「换成这张卡的美化」关着，不会换」。
- 记住了世界书或正则、但一个都没开时，写「全部关掉」。换卡时会把对应的全局世界书或全局正则全部关掉。
- 世界书和正则最多先显示 3 个，多的点「+N」查看全部，再点「收起」。
- 推荐预设找不到时，名字变成琥珀色，下面写「找不到这个预设，不会换」。推荐在别的 API 下设定时，写「在「API」下设的，现在不会换」。

每项右边的「✕」可以解绑。右上角会提示「已解绑「名字」。点这里撤销。」，8 秒内点提示可以恢复。

行末的「⋯」里可以「打开角色档案」或「全部解绑」。「全部解绑」会清掉这张卡记下的推荐、美化和换卡设置，并解开绑定的人设，8 秒内也可以点提示撤销。正在聊的卡还有「记住现在的配套」，与角色档案里的同名按钮相同。表格靠近窗口底部时，「⋯」菜单会往上弹。

手机上改为列表，每张卡先显示头像、名字和两行摘要：第一行是预设、模型，第二行是「人设 X · 世界书 N · 正则 N」。点进去查看整页详情，左上角的「‹ 角色」返回列表。「换到这张卡时」列出预设、模型和人设，下面分别是「只开这些全局世界书」「只开这些全局正则」。每项右边可以「解绑」，底部可以「打开角色档案」「全部解绑」；正在聊的卡还可以「记住现在的配套」。

这里的人设绑定使用酒馆自己的「连接到角色」，与角色档案的「人设」、酒馆人设面板共用同一份数据。

### 预设

顶部显示正在使用的预设，可以切换、编辑，也可以逐条开关预设自带的正则。正则组的开关决定是否允许该组运行；单条正则可以分别开关。

保存的预设可以按系列分组，同系列版本从新到旧排列。工具箱会尝试从名称中识别 `v1.1.7`、`8.0` 等版本号；名称开头相近时，会提示可能属于同一系列。

使用「选择」可以批量归组或删除。点开预设详情，可以：

预设、世界书和美化列表里，点系列标题可收起或展开，收起状态会记住。有名字的系列右边有「编辑」，可改名或「解散系列」；解散后内容回到「其他」，不会删除任何东西，移入或移出系列仍用列表上方的「选择」。「可能是同一系列」的提示平时只显示一行，点「看看」才展开，点「不是」后不再提示这一组。

- 记录作者、发布帖、教程等链接。
- 填写系列、版本和更新说明。
- 查看推荐它的角色卡及同系列其他版本。
- 记录推荐的「API + 模型」。
- 点「换成这个」切换预设。
- 点底部红色的「删除这个预设」删除；正在用的预设不能删除。

预设详情还会显示文件自带的连接，以及酒馆的预设绑定设置是否会让它生效。预设带有酒馆助手脚本时，右栏会显示「预设带的脚本」，可以用「允许运行」控制整组，也可以分别开关文件夹和脚本，不用先换成这个预设；右上角的「编辑 ↗」打开酒馆助手，开关方式与「全局工具箱 › 脚本」相同。

换到带脚本且脚本正在运行的预设时，右上角会提示「预设「名字」带了 N 个脚本，正在运行。点这里查看或关掉。」，点提示打开「脚本」标签。同一个预设每次打开酒馆只提示一次。换卡时自动切预设则不单独弹这条，而是在「自动切换」通知里加一行「预设带了 N 个脚本，正在运行」。

#### 换预设时模型也被换了

酒馆开启「将预设与 API 配置绑定」时，切预设可能连带切换 API 和模型。

工具箱会提示「模型从 A 换成了 B」，可以点一下换回。预设没有保存模型、导致模型被清空时，会自动恢复原来的模型。

### 世界书

这里按使用情况列出世界书：

- 全局开启的世界书，可以关闭或再打开一本。
- 没有绑定到角色卡的世界书。
- 已绑定的世界书，并显示哪些卡在用。

卡里自带但尚未导入的世界书会列在顶部，可以一键全部导入。

使用「选择」可以批量归组或删除。点开详情，可以记录作者、链接、系列、版本和更新说明，查看使用它的角色卡，也可以切换是否作为全局世界书开启。点「在世界书里打开 ↗」进入酒馆编辑面板，点底部红色的「删除这个世界书」删除。

### 正则

这里可以：

- 逐条开关全局正则。
- 点全局正则列表的「选择」，勾选后批量删除。
- 给全局正则标记“属于谁”，用于换卡时自动开关。
- 查看带正则的角色卡和预设，并进入详情。
- 分别控制是否允许卡内、预设内正则运行，以及单条正则的开关。

长列表可以搜索，也可以勾「只看开着的」。正则旁边的编辑按钮会打开酒馆对应面板。酒馆助手脚本在单独的「脚本」标签里管理。

手机或面板较窄、排成一栏时，顶部可以切换「全局 N」「预设 N」「角色卡 N」，一次只显示一段，N 表示数量。「全局 N」列出全局正则，另外两段分别列出带正则的预设和角色卡。宽屏排成两栏时，左边一直显示全局正则，右边切换「预设 N」「角色卡 N」，预设排在角色卡前面。点进详情再返回，仍停在原来选的那一段。

### 脚本

在「全局工具箱」点「脚本」，或输入 `/rbt scripts`，可以查看和开关酒馆助手脚本。需要安装酒馆助手（JS-Slash-Runner）；没装时，这一页会显示「没装酒馆助手（JS-Slash-Runner），所以没有脚本。」，下面的「去看看酒馆助手 ↗」可以打开相关链接。

手机或面板较窄、排成一栏时，顶部可以切换「正在用」「预设 N」「角色卡 N」，一次只显示一段，N 表示数量。「正在用」列出全局脚本、当前预设的脚本和当前角色卡的脚本。宽屏排成两栏时，这些正在用的脚本一直显示在左边。

「全局脚本」一直显示，当前预设和当前角色卡有脚本时，还会显示「预设「名字」的脚本」和「「卡名」的脚本」。每块标题下面用灰字说明运行范围，分别是「所有聊天都会运行」「用这个预设时运行」「和这张卡聊天时运行」，后面显示「N / M 个在运行」。

每块最上面的「允许运行」控制整组脚本，关掉后下面的脚本都不运行。下面每个文件夹和脚本各有一个勾选框，整行都能点，文件夹里的脚本往里缩一格。勾选框和图标对齐脚本名第一行，长说明不会把勾选框挤到手机屏幕外。

文件夹右边的「↓」「↑」可以收起或展开里面的脚本，文件夹图标也会跟着打开或合上。点箭头不会改变勾选状态，文件夹的勾选框仍控制整组脚本。超过 5 个脚本的文件夹默认收起，5 个及以下默认展开。这次打开页面期间会记住收起或展开的状态。预设详情的「预设带的脚本」和角色档案的「角色脚本」也可以这样折叠文件夹。

脚本下面的灰字依次是「可能有前端」、它放的按钮和脚本自带的说明，没运行的行会变淡。屏幕上多了悬浮窗、面板或按钮时，可以先看这几样：

- 「可能有前端」：脚本代码里有画悬浮窗、面板或悬浮按钮的写法时显示。这是读代码判断的，不一定准。只弹提示或酒馆自带弹窗的脚本（比如 MVU）不显示。脚本引用网上的文件时，工具箱会下载那个文件一起看，结果在这台电脑上保存 7 天；下载不了就不显示。
- 按钮：写出输入框上方按钮上的字，比如「按钮「世界书管理」」；超过 3 个时写「等 N 个」。

说明最多先显示两行，写不下时点右边的「↓」展开全文，再点「↑」收起。点箭头不会勾选或取消勾选脚本。右上角的「编辑 ↗」打开酒馆助手，可以在那里编辑、新建或导入脚本。

「预设 N」「角色卡 N」分别列出带脚本的预设和角色卡，点一行打开对应详情。宽屏排成两栏时，在右栏顶部切换这两段，预设排在角色卡前面。点进详情再返回，仍停在原来选的那一段。预设每行显示「N 个脚本」，正在用的标「正在用」；预设和卡没有允许运行时都标「未允许运行」。

不用先换预设，也能开关那个预设里的单个脚本。不是正在聊的卡只能开关整组「允许运行」，单个脚本的勾选框是灰的，提示「要开关单个脚本，先打开这张卡。」，也不显示「编辑 ↗」。预设详情的「预设带的脚本」和角色档案的「角色脚本」使用同样的开关方式。

酒馆助手还没加载好时，点「允许运行」会提示「酒馆助手还没加载好，请过一会儿再试。」。开关没在用的预设里的脚本但保存失败时，勾选框会恢复原样，并提示「没能保存到预设「名字」，请再试一次。」。

### 插件

在顶部粘贴 Git 链接，可以使用酒馆自己的流程安装插件，第三方插件提醒也会照常出现。

已安装的插件各有开关。调整后点「保存并刷新」才会生效。

点插件名可以展开作者和链接。工具箱会读取插件清单中的作者与主页，你也可以补充教程等链接。

### 美化

「美化」用于选择全局美化、管理酒馆主题、记录主题来源，也可通过「选择」批量归组或删除主题。美化详情里列出「用这个美化的卡」。推荐使用红鸟适配美化，它专为三栏界面和手机做，打字和滚动更流畅；手机上搭配「手机沉浸阅读」，正文铺满屏幕，读起来更沉浸。完整说明见下一节。

在这里可以：

- 把工具箱里填写的资料导出为一个文件。
- 导入资料，选择合并或覆盖。
- 查看覆盖世界书前自动保存的备份。
- 处理找不到对应角色卡的档案，将其转给新卡或删除。

删除预设、世界书、美化或全局正则前，也会自动备份到 `data/<用户名>/user/files`；备份失败就不删。删后 15 秒内可点通知撤销。

## 美化：选择外观，保留角色卡自己的界面

红鸟适配美化提供「深色」「浅色」「护眼」三种外观，调整颜色、字体、字号、间距和圆角。推荐使用：它专为三栏界面和手机做，去掉了耗性能的背景模糊，打字和滚动更流畅。布局由「三栏界面」控制。

红鸟适配美化会统一三栏界面、酒馆面板和工具箱窗口的颜色。角色卡在消息里自己画出的状态栏、面板等界面不会被改动。

开着红鸟适配美化时，也会调整酒馆自带面板的间距和鼠标移上去时的显示。标题与下面的控件分开，能展开的行和图标按钮在鼠标移上去时会变亮，勾选框与文字对齐，手机上的勾选行更容易点到。对话补全的预设面板分成几张卡片：预设、长度和生成参数、高级、Logit 偏置、提示词；加了「上下文和回复长度」「生成参数」「高级」三个灰色小标题；「快速提示词编辑」这类能展开的行自成一张小卡片。这些调整只改样子，不改面板里东西的顺序、内容和控件；世界书条目和扩展设置保留各自的排法。

### 开启和选择

在「扩展 › RedBird 工具箱」的「界面」分组里，用「红鸟适配美化」控制开关，在「全局工具箱 › 美化」选择外观和强调色：

- 「深色」：深色背景。
- 「浅色」：米白书页。
- 「护眼」：暖黄纸色。
- 强调色：蓝、珊瑚、粉、紫、绿、石墨。

电脑上聊天正文居中排列，一行约 44 个字，输入栏与正文对齐。手机上推荐开着「手机沉浸阅读」，头像放到名字旁边，正文铺满整个屏幕宽，搭配红鸟适配美化效果最好。消息不加圆角；按钮、窗口等使用统一的圆角和间距。聊天内容以中性色为主，强调色用于按钮、当前项等操作位置。

按钮使用浅底和细边框，文字写明操作，例如「修改」「清除」「删除」；下拉框右边显示箭头。通知使用圆角卡片，左边的彩色图标表示类型，右上角的「✕」可以关闭。

### 管理其他老师做的美化

「全局工具箱 › 美化」左边是「全局美化」（没设美化的卡都用它）。里面先是「红鸟适配美化」的深色、浅色、护眼，再是「别的美化」，显示酒馆现在的主题。四个选项里只有一个打勾、带蓝框；「别的美化」没选中时行末写「换上」，点了先确认再换，选中时点它打开详情。右边一栏的小标题是「全部美化」，列出已安装的酒馆主题；每套标出有几张卡在用。

用着别人的美化时，「别的美化」下面的说明会提醒：别人的美化按酒馆原版界面做，在三栏界面里有的地方可能错位，手机上更明显。推荐用红鸟适配美化，它专为三栏界面和手机做，打字和滚动也更流畅。工具箱不会为单个美化做适配，有问题请找美化作者。

开着「三栏界面」时，「全局美化」这一块最后显示「手机沉浸阅读」，与扩展设置里是同一个开关，说明也相同。

每套主题会标出「带自定义样式」或「只换颜色」，并显示关键配色。主题可以按系列分组，点「选择」可批量归组或删除。

点开详情，可以查看配色，记录作者、链接、版本和更新说明，或点「换成这个」。切换确认框会说明别人的美化在三栏界面和手机上可能错位，推荐使用红鸟适配美化，并写明随时可以在「全局工具箱 › 美化」里换回来；可以勾选「以后不再提醒」。底部红色的「删除这个美化」用于删除；正在用的酒馆主题不能选，也不能删。删除前会确认名称，并备份到 `data/<用户名>/user/files`，备份失败就不删；删后 15 秒内可点通知撤销。

把主题 `.json` 文件拖进导入窗口，会识别为美化。勾选「设为全局美化」时，会关闭红鸟适配美化，避免两套同时生效。删除美化前，如果有卡在用它，确认框会写明有几张，删后和它们聊天时改用全局美化。

### 与酒馆主题一起使用

- 安装工具箱前已经在用带自定义样式的酒馆主题时，红鸟适配美化默认关闭。
- 在酒馆的「用户设置 › 界面主题」里切换主题，会自动关闭红鸟适配美化，并提示换成了哪个主题，点提示即可换回红鸟适配美化。带自定义样式的主题还会提醒可能在三栏界面里错位，手机上更明显；只换颜色或勾过「以后不再提醒」时，不显示这句。
- 使用其他主题时，三栏界面和工具箱会跟随它的颜色，浅色主题也会使用浅底深字。左栏、顶栏和面板遇到半透明底色时，会自动垫一层实色，浅色字垫黑、深色字垫白，保留主题颜色，避免文字压在聊天上看不清；聊天区本身和背景图不受影响。
- 有的主题只给酒馆自己的面板改了字色（比如全局白字、面板白底）。左栏、顶栏和工具箱面板的字和底色太接近时，字会自动换成深色或浅色；看得清的主题不受影响。
- 用着别人带自定义样式的美化、没开红鸟适配美化时，会推荐换用红鸟适配美化，点提示即可切换。电脑上会说明界面样式可能错位；手机上开着「手机沉浸阅读」、主题又改了消息排版时，会说明头像或名字可能错位。每个美化在手机和电脑各提醒一次，换主题时已经弹过提示的，不再重复提醒。

红鸟适配美化专为三栏界面和手机做，推荐搭配「手机沉浸阅读」使用。其他主题可以调整颜色、字体、消息排版和输入框形状；左栏、导航条、聊天区、输入区、面板和工具箱的位置仍由三栏界面控制。「手机沉浸阅读」不依赖红鸟适配美化，用别人的美化时也能开启。

## 三栏界面：把常用入口放到固定位置

在「扩展 › RedBird 工具箱」开启「三栏界面」，或输入 `/rbt shell`。

开启后，左边是最近的聊天和常用入口，中间是聊天，右边是「聊天工具箱」，首页则显示角色画廊。它调整酒馆面板的位置，面板内仍使用酒馆自己的功能，原有的固定和互斥行为保留。左上角使用红色小鸟图标作为品牌标志。

### 左栏：导入、管理和找回最近的卡

左栏包括：

- 首页入口。
- 并排的「导入文件」和「全局工具箱」。
- 酒馆自带的入口：预设、扩展·正则、API、人设、世界书、设置、背景、格式化；API 没连接时有小圆点。
- 「最近聊过」「最近导入」切换和搜索。
- 「最近聊过」每行右下角的「⋯」里有「所有存档」和「删除…」：前者打开这张卡的存档页，后者确认后删除这个存档，删除后不能恢复；若删的是正在聊的存档，会换到这张卡最近的另一个存档。
- 底部一行的「临时聊天」「原版界面」和「⋯」；「⋯」里是酒馆文档、GitHub、Discord 和酒馆版本号。

别的插件加在酒馆顶栏的按钮也会自动出现在左栏图标格里，使用插件自己的图标和名字，打开的面板居中显示，并带标题和关闭按钮。图标超过 8 个时，第 8 格变成「更多」，点开显示全部，最后一格变成「收起」。「世界书」位于第 5 格（第二行第一格），名字后面的灰色小字显示加载了几本，例如「世界书 2」，电脑和手机一样。

刚导入、还没聊过的卡，可以在「最近导入」里找。最近聊天按置顶、今天、昨天、7 天内、30 天内和更早分组。左栏可以用 `«` 收起。

### 首页：浏览和管理角色库

首页中间是角色画廊，以竖版大卡片显示角色立绘。上方可以搜索、筛选、排序和管理。

角色库首页第一行左边是「角色 N」和「＋ 新建」，右边是搜索框；第二行左边是「全部」「置顶」「待处理」（有问题的卡）和「群组」，右边是「按标签筛选」「排序：最近聊过」和「管理」，三个都带图标。手机上搜索框单独一行，筛选、排序、管理只显示图标，放在搜索框右边；选了标签或换了排序时，图标后面会写出现在的值，例如「名称」。还没有角色时，首页直接显示「导入文件」「新建角色」两个按钮。排序可选最近聊过、名称和最近添加，置顶的卡排在最前面。置顶使用酒馆原来的「收藏」，标签也使用酒馆原来的数据。

- 有问题的卡会显示提示，例如世界书没导入、脚本没启用。
- 电脑和手机的角色卡右上角都一直显示「⋯」，不用鼠标悬停；置顶的卡名字前有图钉，群组卡右上角显示「编辑」。
- 点「＋ 新建」，选择新建角色或新建群组。
- 每张角色卡的「⋯」菜单都有置顶或取消置顶、编辑角色、所有存档、导出 PNG、导出 JSON、复制一份和删除；点「所有存档」会先打开这张卡，再进入它的存档页。
- 点「管理」可以多选角色卡，批量置顶、导出、删除，或点底部的「标签」一起添加、移除标签；标签前的勾选框区分「都有」「有的有」「都没有」，点一下可全部加上或全部去掉，也能输入新标签名直接新建并加上，改动在酒馆原版界面中同样可见；群组不能在这里多选。

删除前会确认。聊天记录默认保留，勾选后才一起删除；遇到同名卡时，会显示文件名帮助区分。

电脑、手机和远程打开首页时，角色卡图片都会先显示酒馆缩略图。卡片出现在屏幕上后，工具箱会在后台下载一次原图，缩成宽 600 像素的清晰图，存到浏览器后换上，切换时不闪。以后打开首页直接使用存好的图，每张通常几十 KB，不再下载原图。换过头像后会重新生成。

首次显示每张卡时，会多下载一次原图；角色卡 PNG 常有 1–9MB。同时最多下载 2 张，不挡点卡进入聊天。浏览器开了省流量模式时，只使用缩略图。

#### 调整缩略图清晰度

不用改酒馆配置，首页也会在缩略图后换上清晰图。酒馆默认的头像缩略图是 96×144；想让首次显示的缩略图也更清楚，或改善省流量模式下的图片，可以：

1. 在酒馆的 `config.yaml` 中，将 `thumbnails` 下 `dimensions` 的 `avatar` 调大，例如 `[384, 576]`。
2. 删除 `data/<用户名>/thumbnails/avatar` 文件夹，让酒馆按新尺寸重新生成缩略图。

只改尺寸不会更新已有缩略图。酒馆的配置注释也说明，新尺寸只影响新生成的缩略图。

### 存档页

每条存档按三行排列：第一行是存档名，右边是「⋯」；第二行显示最后一条消息，最多两行；第三行用灰字显示时间、文件大小和消息条数，例如「11/7 15:37 · 3.59 KB · 7 条消息」。「⋯」里有「改名」「导出 JSONL」「导出 TXT」「删除…」，原来的铅笔、导出和骷髅图标不再显示。这些操作仍由酒馆完成，删除前会询问。

### 聊天导航条和状态栏

顶栏在电脑和手机上都按角色名、存档、新聊天、工具箱排列，点角色头像和名字打开酒馆原来的角色编辑页，不再单独显示「编辑角色」按钮。电脑上的存档按钮带存档图标，显示为「存档 · 11-06 02:45 ▾」，今年的存档不写年份，改过名的存档显示你取的名字。手机在角色名下方用灰字显示当前存档名，通过独立的钟表图标按钮打开存档。点存档按钮可以切换或管理这张卡的存档；「新聊天」只在聊天中出现。编辑页标题栏右边写着这张卡的 token 数，例如「130 tokens · 常驻 56」（常驻是每次都会发给 AI 的部分），旁边的小奖杯是聊天统计。新建角色时标题是「新建角色」，填好后点蓝色的「创建角色」。删除按钮一律用垃圾桶图标。

顶栏右侧的状态栏显示当前预设、API 与模型、世界书数量和人设，群聊也会显示：

- 悬停可看完整名称、实际加载的世界书及来源。
- 人设会显示头像、名称和选用来源，例如锁定到当前聊天、关联到角色或群组、默认人设。
- 与角色卡推荐不一致、API 未连接，或开启了别的卡的全局世界书时，会显示琥珀色小点。
- 点状态项打开对应酒馆面板；面板打开时，该项会高亮。
- 空间变窄时，名称会逐步收起为图标。

打开世界书面板时，标题栏列出本次实际加载的世界书，可以点击。换卡后第一次打开，会自动显示这张卡的世界书。

### 世界书面板：先改常用设置

在三栏界面的世界书面板里，条目展开后先显示位置、顺序、触发概率、主要关键字和内容。其余设置收进「更多设置」，点开后按酒馆原来的样子显示。

手机上不用左右滑动。条目收起时，第一行显示展开箭头、开关、标题和触发方式，下面用灰字摘要显示关键词、位置和顺序；触发概率不是 100% 时也会列出。展开后可以再次收起。

### 面板怎么打开和关闭

酒馆面板会居中打开，背景压暗，不与聊天挤在一起。API、预设使用较窄的单栏表单。

每个面板和窗口顶部都有标题栏，左边是图标和标题，右边是圆形关闭按钮「✕」。标题与入口同名，例如「编辑角色 · 霁蓝」「存档 · 霁蓝」。

通常可以点标题栏的「✕」、按 Esc，或点压暗区域关闭。工具箱窗口与酒馆面板不会同时叠着打开。换聊天或回首页时，还开着的面板会自动关闭。

编辑单条提示词时，「取消」「重置」「保存」都在顶部，面板标题栏的「✕」暂时隐藏；要放弃修改，点「取消」。电脑上，提示词编辑界面或角色面板的「高级定义」开着时，按 Esc 不会关闭整个面板。

关闭预设面板时，提示词编辑界面也会关闭，未保存的修改会取消；关闭角色面板时，「高级定义」也会一起关闭。

### 手机上怎么用

窗口窄于 1000px 时：

- 左上角的「☰」打开左栏，左栏不再单列「当前角色」区，「世界书」放在上方图标格子里，名字后面的灰色小字显示加载了几本，例如「世界书 2」。
- 顶栏显示角色名，名字下方用灰字显示当前存档名；点角色名不再打开存档。
- 点角色头像和名字打开「编辑角色」；角色名之后依次是「存档」钟表图标、「新聊天」图标和带文字的「工具箱」，点「存档」可以切换或管理这张卡的存档。
- 存档整页显示；面板、工具箱和导入窗口全屏显示，两栏内容改为一栏。
- 「＋ 新建」和角色卡片上的「⋯」菜单从屏幕底部弹出，最下面有「取消」。
- 默认打开「手机沉浸阅读」，将头像和名字排成一行放在正文上方，时间放在名字下面，正文铺满整个屏幕宽，推荐搭配红鸟适配美化使用；在酒馆「用户设置」里打开显示的消息楼层号、生成时间和 token 数，也放在时间那一行，用灰色小字显示。
- 最后一条消息的操作放在正文下面，按「‹ 1/3 › ✎ ⋯」排列，回复数字在两个箭头中间；还在第一条回复时，包括只有一条回复时，左箭头仍显示为灰色、不能点；点「⋯」后，其余按钮接在同一行后面，放不下才换到下一行。
- 其他消息的右上角只显示「⋯」，编辑收进菜单里，不再多占一行；所有消息里的按钮大小统一，更容易点按。
- 状态栏隐藏。
- 首页「＋ 新建」旁边提供「导入文件」。
- 可点击区域放大，聊天头像和消息留白缩小，为正文留出更多空间。

「扩展 › RedBird 工具箱」的「界面」分组里依次是「三栏界面」「红鸟适配美化」「手机沉浸阅读」。「手机沉浸阅读」只在开着「三栏界面」时显示，默认打开，勾选框下的说明是：「头像放到名字旁边，正文铺满整个屏幕宽。推荐开着，搭配红鸟适配美化效果最好。」用着别人的美化时，在「全局工具箱 › 美化」的主题列表上方也能找到同一个开关。它不依赖红鸟适配美化，用别人的美化时也能开启；关掉后，手机消息恢复酒馆原来的排版和编辑按钮，其他三栏界面功能不变。

#### 手机上编辑消息

在手机三栏界面里，开着「手机沉浸阅读」时，点编辑后，名字下面会出现操作栏：左边是「取消」，右边是蓝色「保存」，中间偏右是「⋯」。

点「⋯」从屏幕底部打开菜单，依次提供「复制成一条新消息」「添加思考过程」「往上移一条」「往下移一条」「删除这条消息」，删除用红色标出。用不了的项不显示。

编辑长消息时，向下滚动后操作栏会停在屏幕顶部，随时可以点「保存」或「取消」。编辑框随文字变高，不在框内单独滚动，可以一直滚到消息最上面。电脑上的编辑方式不变。

### 切回原版界面

可以使用左栏底部的「原版界面」，关闭扩展设置里的「三栏界面」，或输入 `/rbt shell`。之后也可以用同一开关或命令重新开启。

## 数据与备份

工具箱会保存你填写的来源和说明、推荐预设和模型、每张卡记住的配置、正则归属，以及预设、世界书、插件、美化的作者、链接、系列和版本等资料。

资料存两份：

- 酒馆设置：`data/<用户>/settings.json` 中的 `extension_settings.redbird_tools`。
- 工具箱文件：`data/<用户>/user/files/redbird-tools.json`。

多开酒馆页面时，旧页面保存整份酒馆设置，可能覆盖新页面里的资料。工具箱会在写入独立文件前读取已有内容，按每条记录的修改时间合并，也记录删除时间。打开酒馆时，会用独立文件补回设置中过旧的资料。

打开酒馆时读取工具箱存档最多等 5 秒，读写 `redbird-tools.json` 的请求最多等 10 秒，网慢时工具箱不会一直出不来，后续保存也不会卡住不再同步。

### 聊天存档不会被覆盖成只剩开场白

酒馆读聊天时如果出错（手机网络断了一下、请求超时、读角色卡失败），会把这个存档当成新聊天，放上开场白后马上存回原来的文件名，整个存档就只剩开场白了。不装工具箱也会这样。

工具箱会留意正在打开的存档有没有读出来。没读出来时，在重新读成功之前，工具箱不保存这个存档（磁盘上本来就只有一条的新聊天除外），存档保持原样，并提示「这个聊天没有读出来，现在的内容不会保存，以免覆盖原来的存档。请刷新页面，再打开这个聊天。」。刷新后重新打开就能看到原来的内容。单聊和群聊都会拦；自己把消息删到只剩开场白不受影响。

工具箱自己需要刷新聊天显示时（比如允许正则运行、换卡后正则开关变了），只用内存里的聊天重画，不再从磁盘重新读，也不会取消还没到点的自动保存；酒馆助手的前端会重新画出来。

存档已经被覆盖的，可以在酒馆的自动备份里找回：`data/<用户>/backups/` 里存着最近的聊天备份，文件名以 `chat_` 开头、带日期时间（中文角色名会变成一串字母和数字），按修改时间找出事前的那一份。在「存档」里点「导入聊天」选这个文件，或者把它复制回 `data/<用户>/chats/角色名/`。

需要另存一份时，进入「全局工具箱 › 备份」导出。这里导出的是工具箱资料，不是整个酒馆的角色卡和聊天存档备份。

删除预设、世界书、美化或全局正则前，工具箱会先把内容备份到 `data/<用户名>/user/files`；备份失败就不删。删后 15 秒内点「已删除…，点这里撤销」通知即可恢复，世界书原来的全局开启状态和正则原来的位置也会恢复。

遇到问题想反馈时，可以点「聊天工具箱」标题栏的 `⤓` 导出诊断文件：信息流捕获、变量变化和环境报告会存成一个 JSON 文件，放在 `data/<用户>/user/files` 里。

遇到卡顿时，也可以打开浏览器控制台，把带 `[RedBird]` 的几行贴给开发者。某一步超过 50ms，或整个页面卡住超过 300ms 时，会记一行，例如「[RedBird] 慢：换卡自动切换 用了 4005ms」，不会弹提示。

## 开发

安装依赖并构建：

```bash
npm install
npm run watch     # 改代码后自动构建到 dist/
npm test          # 单元测试：来源归因、变量对比等
npm run typecheck
```

本地调试：在 `SillyTavern/data/default-user/extensions/` 下创建指向本仓库的目录链接，Windows 可用 `mklink /J`，然后刷新酒馆。

主要目录：

```text
manifest.json        扩展清单，加载 dist/index.js 和 dist/style.css
src/index.tsx        入口、事件、菜单和 /rbt 命令
src/st/st.ts         与酒馆交互
src/core/            来源归因、消息对齐、变量对比等纯逻辑
src/tools/flow/      信息流捕获
src/tools/vars/      楼层变量和引用搜索
src/tools/env/       环境报告、记住配置、换卡自动应用
src/tools/cards/     角色档案、世界书对比和正则归属
src/shell/           三栏界面、最近聊天、角色库和面板
src/ui/views.ts      视图入口与打开位置
src/ui/pages/        页面组织
src/ui/              工具箱界面
```

`dist/` 需要提交到仓库：从 GitHub 安装时，酒馆直接加载其中的文件。
