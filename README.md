# RedBird 工具箱

一个 SillyTavern 扩展，用来**边玩边学**别人写的预设、大世界卡、MVU 卡和前端卡。

打开方式：输入框左边的魔法棒菜单 →「RedBird 工具箱」，或者输入 `/rbt`（`/rbt flow`、`/rbt vars`、`/rbt env` 直接打开对应页）。

## 现在有的工具

### 信息流
每次真正发送请求时，捕获**这一轮实际发给 AI 的全部消息**，并标出每一段来自哪里：

- 预设里的哪个条目（用的是提示词管理器里的真实名字）
- 角色卡字段（描述、性格、场景、示例对话、卡内系统提示词覆盖）
- 世界书：哪本书的哪一条，这本书属于角色 / 聊天 / 用户设定 / **全局**
- 聊天记录的第几楼，以及插在聊天记录中间的深度注入（显示深度）
- 扩展注入（作者注释、总结、向量等）

顶部的色条显示各来源占了多少 token（估算）。「触发的世界书」页列出这一轮触发的条目，以及在最近消息里匹配到的关键词。

「预览下一轮（不发送）」走的是酒馆自己算 token 时的路径：不会发送请求、不花钱，也不会改动聊天。预览时酒馆不报告逐条触发的世界书，所以世界书只按"@深度"整块显示。

> 目前只支持 Chat Completion 模式。

### 变量
读取每一楼的 MVU `stat_data`（兼容旧版 `[值, "说明"]` 格式），显示这一楼相比上一楼**哪些变量变了**（旧值 → 新值），并在当前生效的世界书和预设里搜索谁会读取这个变量。会把整个 `stat_data` 送进提示词的条目会单独标出来。

### 换卡体检
按作用范围列出现在正在生效的东西：

| 范围 | 换卡时 |
|---|---|
| 全局：全局世界书、全局正则、酒馆助手全局脚本、扩展 | 不变，**最容易串味** |
| 预设：预设正则、预设脚本 | 不变 |
| 用户设定：用户设定绑定的世界书 | 不变 |
| 角色卡：卡内正则、主世界书和附加世界书、角色脚本 | 跟着卡切换 |
| 聊天：聊天世界书 | 跟着聊天切换 |

全局世界书和全局正则可以直接在面板里开关。「记住现在的环境」会给这张卡存一份配置（全局世界书、全局正则开关、预设）；以后换回这张卡时，如果环境不一样会弹出提示，并能一键恢复。扩展本身没法在运行中干净地关掉，所以只做提醒。

## 开发

```bash
npm install
npm run watch     # 改代码后自动构建到 dist/
npm test          # 单元测试（来源归因、变量对比）
npm run typecheck
```

本地调试：在 `SillyTavern/data/default-user/extensions/` 下建一个指向本仓库的目录链接（Windows 用 `mklink /J`），然后刷新酒馆页面。

结构：

```
manifest.json        酒馆扩展清单（加载 dist/index.js、dist/style.css）
src/index.tsx        入口：注册事件、菜单、/rbt 命令、浮动面板
src/st/st.ts         和酒馆打交道的唯一地方（getContext、动态 import 酒馆模块、斜杠命令）
src/core/            纯逻辑，可单测：来源归因、消息对齐、变量对比
src/tools/flow/      信息流：捕获提示词
src/tools/vars/      变量：楼层变量和引用搜索
src/tools/env/       换卡体检：环境报告、每卡配置
src/ui/              Preact 界面
```

`dist/` 需要提交：从 GitHub 安装扩展时，酒馆直接加载里面的文件。
